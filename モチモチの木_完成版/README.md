# モチモチの木 じゆうしんど学しゅう支援アプリ

小学3年・国語「モチモチの木」（光村図書）の自由進度学習を支援する Google Apps Script Web アプリです。
児童が「イチオシの登場人物スライド」を作るまでの記録・振り返り・発表準備を、1人1台端末（Chromebook 等）で行えます。

> ⚠️ **著作権への配慮**：本文・原文は一切表示・保存しません。根拠文などはすべて「児童が教科書を見て自分で入力する」設計です。既存の挿絵・キャラクター素材も使用していません。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `コード.gs` | サーバー側（スプレッドシート連携・データ処理） |
| `index.html` | 画面（SPA。ログイン〜進捗マップ〜場面カード〜並行読書〜まとめ・スライド〜教員ダッシュボード） |

## 導入手順

1. Google スプレッドシートを新規作成する（データ保存先になります）。
2. メニュー **拡張機能 → Apps Script** を開く。
3. `コード.gs` の内容を貼り付け、`index.html` という名前で HTML ファイルを追加して `index.html` の内容を貼り付ける。
4. エディタで関数 `setup` を一度実行する（必要なシートと見本の名簿が自動作成されます）。
   - 実行しなくても、初回アクセス時に自動でシートを用意します。
5. **名簿** シートを開き、`（見本）児童…` の行を、実際のクラスの **出席番号・氏名** に置き換える。
6. **デプロイ → 新しいデプロイ → 種類「ウェブアプリ」**。
   - 「次のユーザーとして実行」= 自分
   - 「アクセスできるユーザー」= 校内ドメインの全員 など、運用に合わせて設定
7. 発行された URL を児童に配布する。

### 教員用ダッシュボード

Web アプリ URL の末尾に `?view=teacher` を付けると教員用ダッシュボードが開きます。

```
https://script.google.com/.../exec?view=teacher
```

- 全児童の進捗一覧（場面1〜5／並行読書／まとめの状況を色分け）
- 場面記録の一覧・検索（人物・場面・性格語でフィルタ）
- 並行読書の記録状況（誰が何冊・どの作品）
- まとめの完成状況一覧
- 「友達の意見」での **氏名表示 ON/OFF** をここで切り替え

## スプレッドシートのシート設計

| シート | 列 |
|---|---|
| 名簿 | 出席番号, 氏名 |
| 場面記録 | タイムスタンプ, 氏名, 場面番号, 登場人物名, 性格語, 根拠文, 理由コメント, 変化コメント |
| 並行読書記録 | タイムスタンプ, 氏名, 作品名, 登場人物名, 性格語, 根拠文, 感想 |
| まとめ | 氏名, イチオシ登場人物, 出典作品, あらすじ, プロフィール, 性格まとめ文, 完成フラグ, 更新日時 |

## 機能一覧（実装済み）

- **① ログイン**：名簿から氏名をボタンで選択（パスワード不要）
- **② 進捗マップ**：場面一〜五＋並行読書＋まとめをカード表示。色分け・完了状況つき。順番は自由（場面は番号順を推奨表示）
- **③ 場面学習カード**：人物選択／性格・気持ち／根拠文（自分で入力）／理由／場面3以降は「変化」欄。提出後に「友達の意見」をランダム数件表示
- **④ 並行読書記録**：代表作プルダウン＋自由入力。これまでの記録一覧を確認
- **⑤ まとめ・発表準備**：人物選択で③④の記録を自動呼び出し→タップで性格まとめ文へコピー。あらすじ（字数めやす表示）・プロフィール・性格まとめ→3枚構成の簡易スライドプレビュー（前へ/次へ、印刷・PDF対応）。「完成」フラグ保存
- **⑥ 教員ダッシュボード**：上記参照

## デザイン方針

- 小学3年生向けに大きめボタン・平易な言葉・ひらがな中心
- 主要な見出しにふりがな（ルビ）
- 場面ごとに色分けして進捗が視覚的にわかる
- Chromebook 等のブラウザ利用を想定

## 開発時のプレビューについて

`index.html` は、GAS 上では `google.script.run` でスプレッドシートと連携し、
素のブラウザで直接開いた場合は `localStorage` を使うモックで動作します（動作確認・画面確認用）。
実運用は必ず GAS にデプロイして使ってください。
