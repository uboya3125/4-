# おすすめパンフレットを作ろう（6年 国語）学習支援アプリ

光村図書 6年国語「おすすめパンフレットを作ろう」の自由進度学習を支援する
GAS（Google Apps Script）ウェブアプリです。

パンフレットそのものを作るツールではなく、**内容の整理・レイアウト構想・原稿執筆**を
支援する思考整理ツールです。完成した原稿は「コピーする」ボタンでコピーして、
Canva等での実際の制作に活用します。

## 機能

- **4桁コードログイン**（学年+組+出席番号。例：6年1組3番 → `6103`）
  - Googleアカウント不要。初回は児童が自分で氏名を登録、2回目以降は「〇〇さんですね？」の確認あり
- **5つのミッション**（自由進度・順次開放）
  1. 見通し・テーマ設定（テーマ・相手・目的）
  2. 情報を集める（情報カード3枚以上）
  3. 構成・レイアウト（用紙形式選択 → 面ごとにテンプレート選択 → ドラッグで微調整）
  4. 原稿を書く（レイアウトの文章ブロックに対応した入力欄が自動生成）
  5. 仕上げ・振り返り（原稿まとめ＋クリップボードコピー）
- **振り返りジャーナル**（1〜10時間目、ミッションとは独立。教員コメント表示）
- **教員ダッシュボード**（パスワード初期値：`1258`。「設定」シートで変更可能）
  - タブ1：ミッション進捗一覧＋児童別詳細（レイアウトの簡易プレビュー付き）＋氏名修正
  - タブ2：振り返り一覧＋その場でコメント返信
  - タブ3：年度設定（過去年度のデータは保持したまま切り替え）
- **年度管理**：全データが「年度＋コード」で分離され、同じURL・同じシートで翌年度も継続利用可能
- 入力は**自動保存**（入力停止後 約2.5秒）。ブラウザ側には保存しないので、別端末でも同じコードで継続可能

## セットアップ手順

1. Googleスプレッドシートを新規作成する
2. メニュー「拡張機能」→「Apps Script」を開く
3. `コード.gs` の内容をエディタの `コード.gs` に貼り付ける
4. 「＋」→「HTML」でファイル名 `index` を作成し、`index.html` の内容を貼り付ける
5. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - **実行するユーザー：自分**
   - **アクセスできるユーザー：全員**
6. 発行されたURLを児童に配布する（ブックマーク登録推奨）

必要なシート（設定・名簿・進捗・振り返り）は**初回アクセス時に自動作成**されます。

## シート構成

| シート | 内容 |
|---|---|
| 設定 | 現在の年度（B1）、教員パスワード（B2） |
| 名簿 | 年度・コード・氏名 |
| 進捗 | 年度・コード・氏名・mission1〜5のデータ(JSON)と完了フラグ・更新日時 |
| 振り返り | 年度・コード・氏名・時間目・内容・記入日時・教員コメント・コメント日時 |

## 運用メモ

- 教員パスワードを変えたいときは「設定」シートのB2を直接編集する（コード変更不要）
- 児童の氏名の誤りは、教員ダッシュボード → 進捗一覧 → 児童の行をクリック → 氏名修正 で直せる
- 年度の切り替えは教員ダッシュボードの「年度設定」タブから。過去データは削除されない
